# FIFA 21 Data Cleaning and Analysis

## Project Overview

This project focuses on cleaning and exploring the
FIFA 21 raw player dataset using Python.

## Tools and Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives

1. Convert player height and weight into numeric values.
2. Remove unnecessary newline characters.
3. Identify players who have been at a club for over 10 years.
4. Convert player values, wages and release clauses into numbers.
5. Clean star-rating columns.
6. Explore highly valuable but relatively underpaid players.

## Dataset

Source:
https://www.kaggle.com/datasets/yagunnersya/fifa-21-messy-raw-dataset-for-cleaning-exploring
